Media Keypad

Control4 media keypad & now-playing display

GitHubBuy me a coffee

The Media Keypad is a NuVoxel touchscreen media keypad. It shows the room's now-playing media (title, artist, cover art, transport, volume) and provides programmable on-screen keypad buttons with RGB accent LEDs.

The intercom is a separate driver. Announcements, SIP intercom and door-station calls need the NuVoxel Keypad Intercom driver added to the project as well, and linked to this one. Add it, then run Actions → Find and Bind Intercom. Until that link exists the panel has media but no intercom — everything else still works, so it fails quietly.

Installation

  • Power the keypad and get it on the network (Ethernet, or Wi-Fi via the on-screen setup QR).
  • The keypad advertises over SDDP — add it from Composer's discovered devices, or add the Media Keypad driver and let it find the panel itself (it learns which unit is its own on first connection and re-binds if the IP moves).
  • Place the driver in the room whose media it should display. Moving it later is picked up automatically.
  • Add the NuVoxel Keypad Intercom driver and run Find and Bind Intercom.

Actions

Identify DeviceFlashes a full-screen splash on the panel for a few seconds — tells you which physical keypad this instance drives.
ReconnectDrops and re-dials the link. For when the driver reads offline but the panel is reachable. Changes no settings.
Forget DeviceUnpairs this driver from its keypad (clears hardware id, MAC, IP and binding) and reopens discovery. Only for swapping in different hardware — an RMA, a spare, or moving the driver to another panel.
Find and Bind IntercomLinks this keypad to its companion intercom driver, preferring one in the same room.
Re-link IntercomRe-announces this keypad to the bound intercom driver so it re-sends the SIP account and call settings. Not SIP registration — that lives in the intercom driver.
Reboot KeypadRestarts the panel. Settings, pairing and firmware are untouched.
Update Firmware (newest)Tells the panel to update itself from GitHub Releases. Does nothing if it is already current.

Connections

Media Keypad NetworkThe link to the panel. The driver dials the device.
Button 1–NLink each on-screen button to a device or scene, like a physical keypad. How many exist depends on the panel size.
NuVoxel Keypad Intercom RelayCarries intercom traffic to the companion driver. Made for you by Find and Bind Intercom.

Properties worth knowing

SourcesWhich sources the on-screen picker offers: Listen, Watch, or Both.
Display Orientation / LayoutRotation, and the now-playing layout (Cover / Fit / Compact).
Active / Idle BrightnessBacklight while in use, and after the idle timeout. Idle = Screen off goes fully dark; a touch wakes it.
Idle TimeoutHow long after the last touch the screen dims. Never dims while media is playing.
Halo Idle ColorThe halo's resting colour — what it shows sitting idle on the wall (nightlight / design accent).
Halo Call ColorThe colour it pulses while an intercom call is ringing. Same physical halo as Halo Idle Color, at a different time. (Renamed from "Halo Ring Color", which read as the colour of the LED ring.)
Halo BrightnessOverall halo brightness, as a percentage.
Room Poll Interval (ms)How often the driver re-reads room media state when Control4 is not pushing events. Only while the room is on and playing; idle rooms poll far slower. Lower = snappier, more Director load. 1000 is fine.
Debug LoggingWhere diagnostics go: Composer's Lua output, the director log, both, or off. Does not change behaviour.
Device MAC OverrideNormally blank. The driver finds its own panel. Set a MAC only to force-bind one specific unit.

Firmware

Two ways, both pulling from this project's GitHub Releases:

  • Remotely — Actions → Update Firmware (newest), or the UpdateFirmware programming command, which takes a Version. Blank means newest; naming a version is the only way to go backwards, for rolling back a bad release.
  • On the panel — Settings → Check for update.

A panel will never install an older image unless a version is named, so the blank form is safe to fire at a whole project. The panel downloads directly over TLS — nothing passes through the Director.
