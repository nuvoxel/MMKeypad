Media Keypad

Control4 media keypad & now-playing display

Overview

The Media Keypad is a NuVoxel touchscreen media keypad. It shows the room's now-playing media (title, artist, cover art, transport, volume) and provides programmable on-screen keypad buttons with RGB accent LEDs. SIP intercom, announcements and door-station call handling are built in — the driver installs an intercom endpoint of its own (shown beneath it in System Design), so there is no companion driver to add and nothing to bind.

Installation

  • Power the keypad and connect it to the network (Wi-Fi setup via the on-device setup page).
  • The keypad advertises over SDDP — add it from Composer's discovered devices, or add the Media Keypad driver and bind its Media Keypad Network connection to the device.
  • Place the driver in the room whose media it should display.

Connections

Media Keypad NetworkIP binding to the keypad (the driver dials the device).
Button 1–6Link each on-screen keypad button to a device/scene, like a physical Control4 keypad.
INTERCOMThe built-in intercom endpoint. Managed by the Communications agent; no manual binding needed.
