# T3 wall-removal tool (factory-fork replica)

A replica of the **Control4 factory removal tool** for the T3 In-Wall touch screen —
the physical prerequisite for pulling deployed T3s to reflash them over USB.

**This is NOT from `MMKeypad_Master`.** It's authored independently:
`T3_RemovalTool.scad` is the source, `gen_stl.py` is the dependency-free generator,
`T3_RemovalTool.dxf` is the flat profile for laser/waterjet. Edit the source and regenerate —
don't hand-edit the STL/DXF.

## Where the profile came from

The T3 has **two bottom latch tabs**, and the factory tool is a two-prong **fork**, not a
plain wedge (thanks for the photo — the first version here was wrong). This profile was
reverse-engineered from a ruler-calibrated photo of the real stamped-steel tool and verified
by overlaying the reconstructed outline back on the photo (match within ~1–2 mm everywhere).

- **Two tall OUTER prongs** slide up the wall behind the screen to release the two latch tabs.
- A **wide central pocket** clears the centre boss/connector.
- Two small **teeth** flank the pocket; a **grip tab** runs along the bottom.
- Overall **~130 mm wide × ~92 mm tall**, **~98 mm clear span between the prongs**. Real part
  is **~1 mm steel**. See `preview.svg`.

### Prong straddle gap (the dimension that must be right)

The first traced outline read the prong inner faces ~2 mm inboard on each side (94 mm clear),
which fouled the power box on the first fit test. The prongs are now shifted outboard to a
**98 mm** clear span (matching the real metal's edges on re-overlay). If it's still tight,
raise `PRONG_SHIFT` at the top of `gen_stl.py` and rerun; if the prongs stop lining up with the
two latch tabs, lower it. One knob, both prongs move symmetrically.

## Use

Same motion Control4 documents: hold the tool flat against the wall, **centred beneath the
screen**, slide it **up** to release the two bottom latches, then **pivot the screen up/off the
top tabs** — don't pull straight out.

## ⚠️ Print thickness vs. fit — the real tension

The steel original is ~1 mm *because the prongs have to fit the thin gap between the wall and
the screen*. That fights print stiffness — thin enough to enter is thin enough to be floppy in
plastic. Two thicknesses ship; try the thinner one first:

| File | Thick | Notes |
|---|---|---|
| `T3_RemovalTool_1p2mm.stl` | 1.2 mm | closest to steel — most likely to enter the gap; a bit floppy |
| `T3_RemovalTool_1p6mm.stl` | 1.6 mm | stiffer — only if 1.2 enters with room to spare |

**Honestly, this part wants to be metal.** If you have laser/waterjet access, cut
`T3_RemovalTool.dxf` from **1 mm steel or aluminium** — that's a true equivalent of the factory
tool and sidesteps the thickness/fit compromise entirely. (Acrylic is a poor choice: brittle in
a pry tool.) The real tool's bottom grip tab is bent ~90° for rigidity; the printed/flat DXF
version leaves it flat — fine as a push surface, or add your own bend/backer if you want stiffness.

## Print (if plastic)

- **PETG** over PLA — less brittle for prying.
- Lay **flat** on the bed; front (flat) face down.
- 100% / near-100% infill at this thinness (it's essentially all perimeters at 1.2–1.6 mm).
- Deburr the prong tips so they slide.

## Regenerate

```
python3 gen_stl.py            # no deps — emits both thickness STLs
# edit THICKNESSES / OUTLINE at the top of gen_stl.py to adjust.
# OpenSCAD (single thickness, set `thickness =` in the .scad):
openscad -o T3_RemovalTool.stl T3_RemovalTool.scad
# DXF is regenerated by the same one-off snippet used to create it (see git history).
```

The outline is the same numbers in all three (`gen_stl.py`, `.scad`, `.dxf`); if you refine the
profile against a real tool, update `OUTLINE` and regenerate.
